A **Full Stack notes management platform** built as a portfolio project to demonstrate modern application development, backend architecture, cloud services, and infrastructure automation.

The project includes:

* 🔐 JWT-based authentication
* 📝 User-specific notes CRUD
* 👤 User-based data management
* 📎 File uploads
* ⚙️ REST API built with NestJS
* 🗄️ PostgreSQL
* ☁️ AWS services simulated locally with LocalStack
* 📬 Amazon SQS and Dead Letter Queue (DLQ)

* 📅 Amazon EventBridge
* 📊 Amazon CloudWatch
* 🔑 AWS Secrets Manager and IAM
* 🏗️ Infrastructure as Code with Terraform
* 🐳 Docker
* 🔄 GitHub Actions and CI/CD

The project demonstrates the integration of **frontend, backend, databases, cloud services, messaging, infrastructure, and automation** in a single application.
